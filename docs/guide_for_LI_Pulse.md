You need to apply a DC voltage to the MW switch to generate IQ pulses. $\pm$0.4 V should work.

The Pulse Blaster channels are defined as follows:

- **CH1**: AOM pulse
- **CH2**: Lock-in reference signal
- **CH3**: MW switch
- **CH4**: For generating an IQ pulse

You need to set the MFLI's external reference to **CH4** of Pulse blaster.  
The demodulated signal is fed into the NIDAQ **ai5** port from the MFLI AUX Output channel.

---

## Pulsed-ODMR
We recommend turning on the AOM before starting measurements to stabilize the diamond's temperature. You can use the idling function in `Pulse_idling.py`.

After that, you can run `Pulsed_ODMR.py`.  
You need to define the following parameters:
- `t_ini`: Initialization time
- `t_pi`: Spin manipulation time
- `power_MW`: Microwave power
- `f_LIA`: Lock-in modulation frequency

Microwaves are generated by the TABOR using `controllTaborTest.py`.
